# 👋 About Me

I'm a **Full-Stack Developer** with **5+ years of experience** building complete web products, from **React/Next.js** interfaces to **Node.js APIs, databases, and cloud deployment**.

I've shipped production platforms across **Healthcare, EdTech, FinTech, and IoT**, including appointment booking, patient management, billing/POS systems, academic ERP modules, payment integrations, and real-time dashboards.
